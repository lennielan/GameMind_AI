# Project Goals

## Short-Term Goals (Next 3 Months)
- **Database Scalability**: Migrate from `sql.js` to `better-sqlite3` to support massive Steam libraries without memory or disk I/O bottlenecks.
- **AI DNA Engine Core**: Replace hardcoded mock data with a stable, dynamic prompt system using either a robust cloud API with graceful failure, or a local open-source LLM.
- **Complete Sync Engine**: Ensure 100% reliable synchronization of Steam games, playtime, and achievements without hitting rate limits.
- **MVP Release**: Deliver a polished, bug-free dashboard, library view, and basic DNA profile to a closed beta group.

## Mid-Term Goals (3-9 Months)
- **Explainable Recommendations**: Implement the recommendation engine that not only suggests games but explains *why* based on the user's DNA traits (e.g., "Because you have high Patience and like Strategy...").
- **Local AI Processing**: Integrate local models to guarantee privacy and zero API costs for users with capable hardware.
- **Advanced Insights**: Generate daily/weekly insights about gaming habits (e.g., "You are playing 30% more RPGs this month").

## Long-Term Goals (1+ Years)
- **Multi-Platform Support**: Expand beyond Steam (Epic Games, GOG, Xbox, PlayStation).
- **Social DNA Matching**: Allow users to compare their Player DNA with friends to find perfect co-op games.
- **Predictive Analytics**: Predict whether a user will enjoy an upcoming unreleased game based on granular mechanic analysis.
