# Release Plan

## Alpha (Internal)
- Currently in this phase.
- Focus: Technical architecture, DB migrations, core AI prompting.

## Closed Beta (Invite Only)
- Target Audience: 50-100 hardcore gamers.
- Objective: Test Steam API rate limits across diverse accounts (e.g., accounts with 50 games vs. accounts with 5,000 games).
- Feedback loop: Gather data on the accuracy of the AI DNA profiling. Do users agree with their "Persona"?

## Release Candidate
- Feature freeze.
- Code optimization, memory leak checks.
- Comprehensive UI/UX polishing.

## 1.0 Public Release
- Launch on GitHub/Website.
- Marketing focus: "An AI that understands your gaming habits better than Steam."
